# CrossfadeMeld

A simple CrossfadeMeld Module for cross device syncing.

CrossfadeMeld is built to be simple and practical, focusing on doing one thing well.

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CrossfadeMeld.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CrossfadeMeld is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
